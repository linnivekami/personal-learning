# 使用指南

这份指南写给学习者：怎样开始、每种模式怎么用、可以对 AI 说什么。规则细节见 `personal-learning/SKILL.md` 与 `references/`。

## 1. 开始之前

1. 让你的 AI agent（任何能读写本地文件的助手）能访问 `personal-learning/` 目录，并把 `SKILL.md` 作为它的技能 / 系统说明。
2. 复制 `assets/learner-profile.md` 到 `data/learner-profile.md`，写下目标、背景、偏好和障碍。
3. 第一次说要学某门课时，AI 会用 `assets/` 模板创建 `data/projects/<课程>/`。一门持续学习的课 = 一个 Project。

> 想让每门课有自己的助教：为每门课开一个独立对话或 bot，让它按 `TEACHING-HANDOFF.md` 启动，只负责这一门；再留一个维护对话负责协议和发布。

## 2. 日常用法速查

| 你说 | 系统会做 |
| --- | --- |
| “这是我今天老师发的资料” | 建资料索引 → 知识地图 → 一道诊断题 → 开始教学 |
| “继续” | 读取 state，从 Next Action 接着做 |
| “我忘了学到哪了” | 不批评、不补课：找回状态，给一个最小任务 |
| “解释一下 p-value” | 先看你哪里卡住，再给最小充分解释或提示 |
| “直接告诉我答案” | 直接回答，不强制出题 |
| “今天只有 10 分钟” | 2 个检索题 + 1 个小应用 + 更新下一步 |
| “下周三考试” | 确认后进入 Exam Mode，记录考试日期 |
| “帮我快速了解这门课” / “做个知识归纳” | 生成知识归纳 HTML |
| “这份 PDF 讲了什么” | Quick Mode：对话内概括，只算接触 |

## 3. 各模式怎么用

### Normal（默认）：扎实掌握

适合长期课程。AI 会按需诊断、讲解、让你检索和应用，并把**有证据的**进步记进 state。你可以随时说：

- “先讲框架再举例” / “先给我一个例子” / “先考我一下” —— 切换教学顺序。
- “给我提示，别直接说答案” / “卡住了，直接讲吧” —— 调整提示程度。
- “我觉得这里不对” —— 质疑会被认真对待，并记录为学习洞察。

### Exam：考前冲刺

说出考试日期和范围即可。允许高频题型、错题强化、模拟考试；可以先生成知识归纳页当复习底图。**考完后**系统会回到 Normal，把重要内容放进长期复习。

示例：“10 月 28 日 Quiz，选择 + 两道短论述，按薄弱点帮我刷题。”

### Knowledge Summary：知识归纳（一页看完一门课）

示例：“帮我快速了解一下这门课”“做一份第 1–6 讲的知识归纳”“给我一张期中复习页”。

AI 会读取课程资料、知识地图和你的学习状态，生成 `data/projects/<课程>/summaries/<主题>.html`。双击即可在浏览器打开，断网也能用。页面里：

- **★ 先看薄弱点**：state 里记录的薄弱点、到期复习、待核验的历史等级排在最前。
- **🗂 知识分类树**：所有知识点一屏可见，圆点颜色是掌握度，点一下直接展开。
- **知识点卡片**：一句话核心 → 详解 → 结构判据（怎么认出该用它）→ 为什么重要 → 例子 → 公式与变量 → 易错点 → 关联 / 先修 → 先答再看的自测。
- **来源标签**：课件原文 / 据课件计算 / 课外补充，一眼分清哪些是课程内容。
- **工具栏**：中英文与公式搜索、全部展开 / 收起、只看薄弱或待复习、按掌握度筛选、查看某个知识点的关联、深浅色、打印 / 存 PDF。

注意：浏览页面、做页面自测、勾选“已复习”都**不会**改变你的掌握度——它们只是复习工具。想让自测算数，把答案发给对应课程的助教：“这是知识归纳里 2.3 的自测答案：……”。

### Quick：对话内概括

示例：“这份讲义讲了什么？”“用三点概括这一章”。只记为“接触过”，不会假装你学会了。

## 4. 掌握度怎么看

| 等级 | 含义 | 需要的证据 |
| --- | --- | --- |
| 0 | 未知 | 还没有证据 |
| 1 | 接触 | 讲过、认出过或在提示下做对 |
| 2 | 首次独立 | 第一次无提示做对 |
| 3 | 可用 | 能独立解释和应用，并在 ≥2 天后无提示复测通过 |
| 4 | 变式 | 再加无提示变式题通过 |
| 5 | 迁移 | 再加结构不同的新领域迁移 |

- “待核验”表示这是旧规则下的历史等级，还缺某项证据；不会因此罚你补测，只在影响当前学习时加一道小题。
- 信心分（1–10）只在关键题问你；没问就写“未采集”，不会替你编。

## 5. 小贴士

- 每次只做一个下一步；中断几天直接说“继续”。
- 新资料直接丢给负责这门课的助教；跨课程的问题分别问各自的助教，避免记录混在一起。
- 想改教学规则（比如加新功能）找维护对话，不要让课程助教改协议。
