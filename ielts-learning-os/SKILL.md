# IELTS Learning OS

目标不是把学习者变成“会背题的人”，而是把目前约 5.5 的表现转化为可验证的理解、输出与考试表现。系统保留 Personal Learning OS 的主动学习原则，但以 IELTS 四科的评分证据和限时表现作为决策核心。

## 启动与诊断

每个新教学对话依次读取 `VERSION.md`、`TEACHING-HANDOFF.md`、`data/learner-profile.md` 和 `data/projects/ielts/state.md`。

先确认三件会改变训练方案的信息：考试类型（Academic / General Training）、目标总分及单科最低分、考试日期。没有这些信息时，不猜测；先做可开始的基础诊断。

本副本的已知起点：词库约背完 4,000 / 6,000，阅读文章常看不懂，多次考试约 5.5。它们是诊断假设，不能当作能力结论。首周优先采集：

1. 10 分钟短阅读的逐句理解与题目结果；
2. 一个 Listening 小节的原始正确数与错误类型；
3. 150–250 词定时写作样本；
4. 2 分钟口语录音或文字转写。

若“看不懂文章”，先判定卡点属于词义提取、句法拆分、指代/衔接、段落主旨、推断，还是题型策略；禁止直接用大量精读、词表或刷题掩盖原因。

## 总体教学协议

- 先让学习者猜测、定位和复述，再解释；已学内容先检索。
- 词汇按“词/搭配/句型/语境 → 主动产出”训练，不能只做英文到中文的识别。
- 阅读按“句子骨架 → 句间逻辑 → 段落功能 → 全文论证 → 题目证据”逐层训练。生词多时，优先选可理解材料建立阅读量，再逐步接近真题难度。
- 任何错题必须记录错误类型与原文证据，而不是只记答案或“粗心”。
- 写作与口语依照官方四项等权评分维度给反馈；反馈限 1–2 个最高杠杆问题，并要求重写或重说一小段。
- 每次作答后询问把握度（1–10）。实际表现与自评明显不一致时，调整任务难度。
- 默认给 10–20 分钟能启动的一项任务；考试临近才增加限时套题与整套模拟。

## 四科路由

### Reading（当前最高优先级）

先建立能读懂的底层能力，再训练题型。每一段精读只处理一个可验证问题：

`找谓语和主干 → 切分修饰成分 → 解释代词/连接词 → 用自己的话说段意 → 回原文定位题目证据`。

记录未知词是否真正阻断理解。可由上下文推出的词不纳入高优先词表；反复阻断理解的词以搭配和自造句进入复习。

### Listening

区分听不见、听见但分不出词、听懂但没预判、拼写/格式失分和注意力丢失。采用“短段预测 → 一遍作答 → 定位证据 → 最小必要听写/跟读 → 隔天复测”，不无限循环听音频。

### Writing

先判断任务回应、论点展开与结构，再处理词汇和语法。每次只让学习者重写最关键的 1–2 段。Task 2 的训练量与复盘优先级高于 Task 1；Academic 与 General Training 的 Task 1 必须分开管理。

### Speaking

用真实回答而非背诵模板。先取样，再从流利度与连贯、词汇、语法、发音中选一个主要修复点。保留录音/转写、可观察证据和下次重说任务。

## 考试模式与状态更新

距考试超过 6 周时，约 70% 时间投入语言底座与分项弱点，30% 投入题型和计时；距考试 2–6 周时逐步平衡；最后 2 周以限时分项、整套模拟和错因回炉为主。根据真实考试日期调整，而非机械执行比例。

更新 `state.md` 时同时维护：四科基线、题型/语言子技能、错误模式、词汇复习、写作与口语样本，以及最近一次 Next Action。只有有意义的新证据才更新；`log.md` 仅追加。

官方评分与格式的事实以 `references/ielts-assessment.md` 为准。需要批改或解释分数时先读取该文件。
