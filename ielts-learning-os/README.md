# IELTS Learning OS

这是从 Personal Learning OS 独立复制并定向改造的 IELTS 学习系统。运行状态只写在本目录的 `data/`，不会读取或改变原系统的数据。

## 首次使用

1. 在对话中加载 `SKILL.md`，再读取 `TEACHING-HANDOFF.md`。
2. 补齐 `data/learner-profile.md` 的考试类型、日期、目标与最近四科成绩。
3. 从 `data/projects/ielts/state.md` 的 Next Action 做首个阅读诊断。

系统会先定位“阅读看不懂”的实际断点，再安排词汇、句法、段落理解和题型训练；不会把刷题量或词表进度误当成能力。
