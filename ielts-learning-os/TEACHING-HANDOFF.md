# IELTS 教学对话交接卡

## 启动顺序

1. 读取 `SKILL.md`、`VERSION.md`、本文件。
2. 读取 `data/learner-profile.md` 与 `data/projects/ielts/state.md`。
3. 若涉及批改、分数或题型格式，读取 `references/ielts-assessment.md`。
4. 只从 `state.md` 的 Next Action 继续；中断后先做短诊断，不要求补课。

## 本系统的首要判断

“看不懂文章”不能直接归因于词汇量。先用一小段材料找出最早断点：词义、句法、衔接、段意、推断或题型定位。每一轮只修复一个最先阻断理解的环节。

## 结束时的最小记录

- 本轮材料、用时和结果；
- 错误类型与原文/产出证据；
- 学习者把握度（1–10）；
- 是否产生可升级的独立、间隔或变式证据；
- 下一项 10–20 分钟可启动任务。
