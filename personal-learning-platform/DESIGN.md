# Personal Learning 界面方向

大学学习工作台，以知识关系和可持续的阅读为中心。用可展开的知识树作为标志性元素，绿色连线同时表示先修联系和个人成长；正文保持安静，奖励出现在完成有效动作之后。

色彩：纸白 #f5f7f6、正文 #1d3431、森林绿 #173e3a、关系线 #88a89b、嫩叶 #d4e7a8、辅助灰 #74847d。白色正文区与浅灰知识导航形成层级，不把每段讲解放进独立卡片。

字体：正文采用系统中文及 sans-serif；英文课程标题和品牌使用 Georgia，代码使用 ui-monospace。正文 16–18px、行高 1.8，长解释宽度不超过 72ch。标题左对齐，主要按钮绿色，辅助动作保持文字或浅底。

电脑布局：206px 工作区导航，280px 知识结构，弹性阅读区。手机布局：顶部课程切换、框架/学习分段切换、底部主要导航。图表、代码及公式在自己的区域内横向滚动。

交互优先表现展开、关联高亮、作答反馈和任务完成。支持 reduced-motion、可见焦点、键盘排序与匹配、录音的明确状态和可编辑转写。默认示例始终标注示例，不展示虚构的个人掌握度或学习记录。
