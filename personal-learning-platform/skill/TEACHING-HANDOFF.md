# 教学对话交接卡

当前版本见 `VERSION.md`。本文件是具体教学对话的最小启动说明。

## 启动顺序

1. 读取 `SKILL.md`、`VERSION.md`、本文件；发生评估或升级时读 `references/mastery-scale.md`。
2. 读取 `data/learner-profile.md` 并确认 Project；读取项目 state，需要时再读 map / index / log。
3. 首句简短说明版本和项目，不能混合课程。升级后重新读取上述文件。

## 共享工具

读取 `references/teaching-contract.md`。结构化证据通过 `scripts/state.mjs` 预览、revision 检查及幂等提交；Markdown 只做对应增量。新高等级使用 events 审计，不依赖中文关键词判断。作答后复查 Memory 与 Next Action，不能继续保留已完成的原题。见 SKILL.md 的 v2 说明。

## 教学与记录

- 明确目标后从 Next Action 继续。需要诊断时优先一道区分性问题；简单定义、直接答案请求和已有充分证据时直接解释。
- 要求思维导图或知识点总览时，读取 `references/mind-map.md` 和目标项目地图，先展示浅层结构，按请求展开分支或查看关联；仅浏览不强制测试、不改 Mastery、Last Verified 或 Next Action。状态叠加按需从 state 读取，历史待核验标记一并保留。
- 保留检索、推导及提示偏好，按基础和反馈选择直接解释、例题或提示跳级。连续两次未理解时切换表示或补最小前置知识。
- 重要误解或复杂新知识后按需检验，可从自然交互收集证据；不每轮强制出题。
- 只按实际能力、辅助和日期增量更新目标项目数据；历史过程只追加 log。关键任务按需采集信心，未问如实记录。
- 等级累积：3 需独立解释、应用及≥2天无提示复测；4 再加变式；5 再加新领域迁移。辅助成功、同题复写不触发独立升级，算术失误不自动降低概念能力。
- 历史“待按 v1.2 核验”的分数及结课结论保留来源，不作为自动跳过、新结课或升级的充分依据。缺口阻碍当前任务时才加入最小复测。
- 结束时简要报告新证据与必要状态变化；持续学习给一个可启动任务，短问答可直接结束。
