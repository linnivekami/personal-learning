# 完整发布验收

这份记录区分规则验证、真实浏览器验证和外部服务验证。不把内部样例称为 MVP 或正式完成的平台发布，不把规则测试称为长期学习效果证明。

## 本地已验证

- TypeScript 编译、Vite 和 Workers ESM 构建。
- 教学累计证据、识别/提示边界、≥2 天保持、失败只降一级、辅助补救不恢复、不相关回忆不清除应用障碍、模式切换。
- 用户与课程隔离、管理员权限、跨来源请求防护、提示记录、重复提交和状态冲突。
- 并发预算预占、幂等结算、费用异常；WAV 时长校验、音频分段合并、流式 ZIP。
- 版本化导入预览、全部校验后提交、原始历史事件/辅助/日期和笔记保留；六门私人历史迁移留在本地 private/，不公开。
- 浏览器真实 SQLite WASM OO1 执行；Pyodide、NumPy、pandas 与 Matplotlib 图表；独立运行来源与无账号接口。

最终测试数量和浏览器状态以 `npm run check`、`npm run test:browser` 的最新输出及 test-results/ 为准，不在文档硬编码固定记录数。

## DeepSeek 接入（2026-10-19）

已用真实密钥验证：Responses API 结构化讲解（含 schema 失败重试一次）、自由作答评估、图像输入、JSON schema 和 Search/Fetch。模型名由服务端常量固定为 `deepseek-flash`。尚未完成上表“完整 30 分钟学习”场景，也未在登录后的线上账号中复测付费调用；这两项仍需按发布闸门验收。
