# Personal Learning OS — Version

## v2.1.0 — 2026-10-19

- 新增 **Knowledge Summary Mode（知识归纳）**，取代 Mind Map Mode：按课程资料、知识地图与 state 生成单文件 HTML——薄弱点优先、知识分类树、知识点卡片（一句话核心、详解、结构判据、例子、公式、易错点、关联 / 先修、先答再看的自测）、公式表、易错点汇总与资料覆盖缺口。
- 新增 `references/knowledge-summary.md`、`assets/knowledge-summary-template.html`（零外部依赖：搜索、筛选、展开 / 收起、关联视图、掌握度徽章、深浅色、打印、移动端）、`assets/knowledge-summary-cards-template.json`、`scripts/build_summary.py` 与公开演示 `examples/knowledge-summary-demo/`。
- 掌握度徽章来自 state 只读快照，区分“待按 v1.2 核验”“合并记录”“未记录”；浏览、页面自测与本机“已复习”勾选都不是证据，不改 Mastery 或 Next Action。来源统一标注“课件原文 / 据课件计算 / 课外补充”。
- `references/mind-map.md` 改为停用跳转说明；知识地图节点可带稳定 `#id`，与卡片对齐；资料索引新增覆盖缺口。
- 统一 SKILL、modes、交接卡与模板；明确维护者与各课程助教的分工。新的或变更的 Level ≥2 可用 Evidence 中的 `累积证据：` 段或结构化 events 审计，纯文件型助教不再被迫使用 JSON。
- 课程分工与历史核验要点迁入私有 `data/handoff-status.md`；公开文件不再出现具体课程与进度。新增 `docs/ARCHITECTURE.md`、`docs/USER-GUIDE.md`，旧版使用指南移入 `docs/history/`。
- 审计：缺少 `rg` 时回退 `grep`；检查新模式文件、HTML 模板无外部依赖、知识归纳 JSON 校验及公开文件隐私。按交接要求为一条历史等级补“待按 v1.2 核验”标记（2026-10-11 已通过无提示间隔复测，仍缺 Level 4 变式证据），未改分数与日期。

## v2.0.0 — 2026-10-18

- 与 Personal Learning 平台共享版本化教学契约、状态引擎和预算规则；保留原 Skill 及全部历史项目。
- 新增结构化事件预览、版本检查、幂等提交与状态审计；独立能力、提示、识别与保持范围明确区分。
- 复测、复习安排与 Next Action 同步；修复一个项目已完成任务仍待办的问题，未制造学习表现。
- 各项目迁移保留原始日志、日期与待核验标记；文件在本机私有目录，不进入公开源码或示例。
- 新增平台源码、配置及验收文件；第三方服务仍需账号配置并通过真实集成验收后才能正式上线。

## v1.3.0 — 2026-10-08

- 新增 Mind Map Mode，用简洁导图快速浏览课程、章节或主题知识点，支持分支展开、返回总览及关联查看。
- 按需从 state 叠加掌握度与薄弱点；保留未记录及历史待核验边界，浏览不触发掌握升级或覆盖学习任务。
- 新增 `references/mind-map.md`，同步入口、模式规则、知识地图模板、教学交接与使用说明；先修状态统一留在 state。
- 项目运行数据与 IELTS 系统保持原内容；验证记录保存在本地 `tests/mind-map-v1.3.0/`（不公开）。

## v1.2.0 — 2026-10-08

- 教学改为按需诊断、最小充分解释与理解验证；保留教学偏好并允许策略切换和提示跳级。
- Mastery 使用累积门槛；明确独立、辅助、即时应用与间隔保持的证据边界。
- 局部算术和表达失误不自动降概念等级；信心按关键任务采集并按同题表现校准。
- 保留历史分数、日期与结课记录；缺失证据标“待按 v1.2 核验”，不作为自动跳过或新结课的充分依据。
- 同步参考文件、模板及交接卡，修复冲突状态条目；扩展结构与状态审计。
- 教学行为测试、评分及历史核验清单保存在本地 `tests/tutor-v1.2.0/`（不公开）；IELTS 系统未纳入本次升级。

## v1.1.1 — 2026-09-10

- 建立 `personal-learning/` 为唯一可编辑源目录；`personal-learning-skill.zip` 与 `dist/personal-learning.zip` 仅为发布产物。
- 明确教学对话与维护对话的职责、交接格式与升级刷新机制。
- 将一门课程纳入标准项目目录。

## 版本使用规则

- 教学对话启动时必须读取本文件；报告其读取的版本号。
- 协议、模板或目录结构变更时，维护对话提升版本并记录变更。
- 发布前必须运行归档校验；发布包版本应与本文件一致。
