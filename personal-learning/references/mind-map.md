# Mind Map Mode（已停用）→ 知识归纳

> **v2.1.0 起停用。** 用户说“思维导图 / 知识点总览 / 用图快速浏览”时，改用知识归纳模式，规则见 [`knowledge-summary.md`](knowledge-summary.md)。

原导图能力在知识归纳中的对应：

| 原导图操作 | 现在 |
| --- | --- |
| 总览与分支编号 | HTML 的“知识分类树”和目录；对话中用分类树摘要 |
| 展开 3 / 展开某概念 | 点击分类或知识点芯片，展开对应卡片 |
| 返回总览 | “返回总览”按钮或分类树 |
| 查看关联 | 卡片“查看关联”，按先修 / 对比 / 应用等关系筛选 |
| 显示掌握度 / 只看薄弱点 | state 只读快照徽章、“★ 薄弱 / 待复习”与掌握度筛选 |

证据边界不变：浏览不改 Mastery、Last Verified、Memory、log 或 Next Action；历史待核验标记随等级显示。本文件只保留为旧对话的跳转说明，原全文见本地 `archive/2026-10-19-pre-v2.1.0/`。
