# Mastery 等级与掌握判定

本文件是 Mastery 与信心校准的唯一规范来源。等级只属于实际涉及的知识点，不能由一题计算推广到整个章节或理论。

## 累积等级（整数 0–5）

| Level | 状态 | 必须具备的证据 |
| ----- | ---- | -------------- |
| 0 | Unknown | 尚未接触本节点，或连其接触/证据范围也未知；不等于已证明不会 |
| 1 | Familiar | 接触、识别或辅助成功；尚未独立完成 |
| 2 | Developing | 首次无提示独立正确解释或应用；只承认实际涉及的能力 |
| 3 | Functional | 已独立解释且应用通过，并在 ≥2 天后的无提示复测通过 |
| 4 | Strong | 满足 Level 3 的全部条件，另有无提示变式应用通过 |
| 5 | Transferable | 满足 Level 4 的全部条件，另有结构不同的新领域无提示迁移通过 |

**Level 3 = 可用掌握。所有门槛累积，不能从一次变式或迁移直接绕过保持证据。** 同日独立解释、应用及变式通过可记录为强应用证据，尚无间隔证据时最高为 2。已有可靠证据可复用，无需为升一级重复测一遍。

普通教学中已明确讲到一个节点，即可记其 Exposure 并到 Level 1，即使没有学生作答；Last Verified 仍只用实际作答日期。Level 1 表示接触而非能力已证明。用户指定 Quick Mode 时遵守只更新 Exposure 的约定，不自动改变 Mastery。

## 独立性与保持

- 无提示：未提供本题方向、关键步骤、答案或可直接复制的对应解法；自主选择方法且作答正确。
- 提示后成功、选择题识别及看答案后重做分别注明辅助 / 识别 / 同题复写，不能充当无提示自由应用证据。识别题只证明它实际区分的能力。
- 给出提示或答案后，须在未见过的新题中无提示完成才能收集新的独立应用证据；即时新题仍不证明保持。
- 间隔从最近一次该知识点的实质教学、提示或成功独立学习开始计算；≥2 天后，先无提示复测，再补救。只有日期时按日期差判断，注明日期粒度；不知道时间或过程时记证据不足，不补造。
- 间隔复测必须覆盖该等级所称的具体能力。仅背出定义不能证明应用，换数字不能自动证明新领域迁移。
- Evidence 可写 `能力：…；结果：Demonstrated；辅助：无提示；日期：…；间隔：…`，沿用现有文本列；log 保留题目、答案和证据来源。结果标签不构成另一套掌握等级。
- 新的或变更的 Level ≥2 在 Evidence 中写 `累积证据：` 段，逐项列出支撑本等级的能力与日期，例如 `累积证据：独立解释 2026-10-05；无提示应用 2026-10-05；≥2天无提示复测 2026-10-08；无提示变式 2026-10-08`。审计按等级检查其中是否含“无提示 / 解释 / 应用 / 复测 / 变式 / 迁移”。使用结构化 events 时可不写此段。

## 错误与等级调整

答错或部分答对不升级，先分类再判断证据范围：

- 局部算术、拼写或表达失误：保留已证明的概念能力，纠正局部；记录该技能的错误，不自动降低整个知识点等级。
- 表达含糊、题目缺数据、未答或 Unknown：证据不足，不降级，不将其当成学生已被证实不会。
- 可靠无提示间隔复测确认概念、关键推理或必要程序失败：仅将受影响知识点降 1 级（最低为 1），登记原因，2–3 天内短期复测。辅助补救成功不立刻升回。
- 不用后续讲解当作学生表现，不因维护改变 Last Verified，不以学习时长替代证据。

## 历史兼容

v1.1.1 及更早的分数和结课记录保留。证据缺失时在该行 Evidence 写“待按 v1.2 核验：<具体缺口>”；只有辅助成功的历史 Level 2 也须标注缺少无提示证据。

待核验分数不用于自动跳过基础、继续升级或新结课。保留既定目标，仅当该缺口影响当前任务时加入一道最小复测，不批量补测。新复测后按全部可靠证据重新确定现行等级，说明这是证据核验，不把规则调整称为能力退步。

## Confidence 按需自评

关键诊断、重要复测或出现明显信心/表现偏差时采集 1–10，优先在提问中附“可一起给出把握度”。避免为了信心单独增加一轮；学生已经报告时不重复问。简单定义或明确直接答案请求不采集。

没有本轮自评就写“未采集（本轮未询问）”或“未采集（学生未报告）”，不得推断数字。保留上次自评时注明题目与来源日期，不能将它用于本题校准。

| 同一任务的观察 | 记录与应对 |
| -------------- | ---------- |
| 高信心（≥7）且关键判断错误 | 本题存在过度信心信号；定位错误并安排必要独立检验，不据此诊断稳定特质 |
| 低信心（≤4）且无提示独立正确 | 本题可能低估；肯定具体证据，继续适当难度，不反复训练已证明的基础 |
| 高信心且首次独立答对、尚无保持证据 | 本题表现与信心一致，长期校准待观察；等级 2 不等于过度自信 |
| 信心或客观证据不足 | 校准未知；记录缺口，不比较 1–10 与 0–5 两种量表的数值 |

历史偏差标签保留来源，并按新规则标注待核验；不能只因规则变更伪造新的信心判断。

## 效果指标

观察独立检索、应用、迁移、保持、错误复发、任务信心校准，以及达到独立作答所需交互。Prompt 长度、模块数量、交互轮数增多均不代表学习效果变好。脚本行为测试能验证规则执行，不能证明真实学生长期学习收益。
