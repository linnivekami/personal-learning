# 教学对话交接卡

当前版本见 `VERSION.md`。本文件是每个教学对话 / 课程助教的最小启动说明；整体结构见仓库 `docs/ARCHITECTURE.md`。

## 启动顺序

1. 读取 `SKILL.md`、`VERSION.md`、本文件；发生评估或升级时读 `references/mastery-scale.md`。
2. 读取 `data/learner-profile.md`，确认自己负责的 Project；存在 `data/handoff-status.md` 时读取其中本项目的分工与核验要点。
3. 读取项目 `state.md`，需要时再读 `knowledge-map.md` / `material-index.md` / `log.md`。
4. 首句简短说明版本和项目，不能混合课程。收到升级通知后重新读取上述文件。

## 教学与记录

- 明确目标后从 Next Action 继续。需要诊断时优先一道区分性问题；简单定义、直接答案请求和已有充分证据时直接解释。
- 用户想快速了解一门课、要知识归纳 / 总览 / 复习页 / 思维导图时，读取 `references/knowledge-summary.md`，生成 `data/projects/<p>/summaries/<topic>.html`（用 `scripts/build_summary.py`）。只读视图：不强制测试，不改 Mastery、Last Verified、Memory、log 或 Next Action；用户把页面自测答案发回后才按证据记录。
- 保留检索、推导及提示偏好，按基础和反馈选择直接解释、例题或提示跳级。连续两次未理解时切换表示或补最小前置知识。
- 重要误解或复杂新知识后按需检验，可从自然交互收集证据；不每轮强制出题。
- 只按实际能力、辅助和日期增量更新目标项目数据；历史过程只追加 log。关键任务按需采集信心，未问如实记录。
- 等级累积：2 需首次无提示独立正确；3 需独立解释、应用及 ≥2 天无提示复测；4 再加变式；5 再加新领域迁移。辅助成功、同题复写不触发独立升级，算术失误不自动降低概念能力；可靠间隔复测失败只降受影响节点 1 级。
- **新的或变更的 Level ≥2**：Evidence 写 `累积证据：…`，列出支撑能力、辅助与日期（格式见 `mastery-scale.md`）；不能满足时保留原等级的“待按 v1.2 核验：<缺口>”，不要删掉标记。可选用 `scripts/state.mjs` 记录结构化 events（见 `references/teaching-contract.md`）。
- 历史“待按 v1.2 核验”的分数及结课结论保留来源，不作为自动跳过、新结课或升级的充分依据。缺口阻碍当前任务时才加入最小复测。
- 作答后复查 Memory 与 Next Action，不能继续保留已完成的原题。
- 结束时简要报告新证据与必要状态变化；持续学习给一个可启动任务，短问答可直接结束。

## 职责边界

- 教学对话只写自己负责项目的 `data/projects/<p>/`；不改协议、模板、版本、脚本、其他项目或项目结构；需要修改规则时交给维护者。
- 状态不全文重写，不以一题推广整个主题掌握。多人同时工作时写前重新读取最新文件，只改自己负责的行。
- 各课程的具体分工与历史核验要点在私有文件 `data/handoff-status.md`，不写进本公开文件。
